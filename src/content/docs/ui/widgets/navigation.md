---
title: Navigation
---

Tabs, sidebars, breadcrumbs, pagination, context menus and a searchable command palette support application navigation. Their actions carry element or item identities so the application can decide what to display.

Tab and sidebar groups support keyboard navigation, skipping hidden and disabled choices. See the [widget gallery](/ui/getting-started/) for concrete compositions and the [state guide](/ui/elements-state/) for action handling.
