## Choose a navigation control

| Control | Purpose |
| --- | --- |
| Tabs | Switch between related pages. |
| Sidebar | Navigate groups or sections. |
| Breadcrumbs | Show a path through a hierarchy. |
| Pagination | Navigate between numbered pages. |
| Context menu | Offer actions for the current context. |
| Command palette | Search and activate commands in a modal overlay. |

## Interaction

Tab and sidebar groups use keyboard navigation and skip hidden or disabled choices. Context menus can be opened with right-click, Menu, or Shift+F10. Actions carry element or item identities so the application can decide what to display.

See the [gallery](/ui/getting-started/) for complete compositions and [Elements and state](/ui/elements-state/) for handling actions.
