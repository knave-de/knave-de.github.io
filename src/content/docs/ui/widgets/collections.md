---
title: Collections
---

Lists, icon grids, trees and tables present application-supplied data. Collections use stable item identities and paint visible rows rather than creating one retained element for every item. `Action::Selected` identifies the owner and selected item; `ItemActivated` signals activation.

Trees support expansion and parent/child keyboard navigation. Tables support column sorting and stable row identities. They do not fetch application data or provide spreadsheet editing. Try the [gallery](/ui/getting-started/) for examples.
