---
title: Widgets
---

Knave UI provides widgets and compositions for common application interfaces. Explore working controls and their interaction states in the [widget gallery](/ui/getting-started/).

| Family | Examples |
| --- | --- |
| [Typography and display](/ui/widgets/typography/) | Text, headings, paragraphs, links, icons, images, badges and separators. |
| [Buttons and actions](/ui/widgets/buttons/) | Buttons, split buttons, toggles, disabled and busy states. |
| [Inputs and forms](/ui/widgets/inputs/) | Text, password, multiline, search and numeric inputs; sliders, dropdowns, combo boxes and color pickers. |
| [Selection](/ui/widgets/selection/) | Checkboxes, switches, radio groups, segmented controls and selectable rows. |
| [Navigation](/ui/widgets/navigation/) | Tabs, sidebars, breadcrumbs, pagination and command palettes. |
| [Collections](/ui/widgets/collections/) | Lists, icon grids, trees and tables. |
| [Feedback and overlays](/ui/widgets/feedback/) | Progress, spinners, alerts, toasts, menus and dialogs. |

These are toolkit interfaces: collections consume application-provided data rather than fetching it themselves. [Elements and state](/ui/elements-state/) explains how controls report actions. See [CSS selectors](/css/selectors/) for component and painted-part selectors.
