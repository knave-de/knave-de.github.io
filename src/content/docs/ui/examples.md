title: Examples

The Knave UI checkout contains complete standalone applications:

| Example | Run from the checkout | Demonstrates |
| --- | --- | --- |
| Widget gallery | `cargo run -p knave-app --example widget-gallery --locked` | Controls, layout, interaction and state. |
| Opacity demo | `cargo run -p knave-app --example opacity-demo --locked` | CSS opacity applied to buttons. |

Both run independently of Knave Shell on a supported Wayland or X11 desktop. Start with [Getting Started](/ui/getting-started/) and use [Elements and state](/ui/elements-state/) to understand how actions connect to your application.
