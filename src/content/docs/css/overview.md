---
title: CSS overview
---

Knave UI uses a bounded CSS language to style retained elements and their painted parts. It is shared by standalone applications and Knave Shell. CSS controls supported appearance and some dimensions; Rust still defines the element tree and its layout behavior.

Start with [selectors](/css/selectors/), then look up [states](/css/states/) and [properties](/css/properties/). [Theme variables](/css/variables/) and the [cascade](/css/cascade/) explain how styles combine. Read [limitations](/css/limitations/) before applying browser CSS.
