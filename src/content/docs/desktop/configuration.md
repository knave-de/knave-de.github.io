---
title: Configuration
---
Knave's canonical configuration is `~/.config/knave/config.toml`. The shell consumes projections of this configuration rather than maintaining a separate shell configuration file.

The Knave CLI provides `config path`, `config init`, `config check`, and `config print` commands. For current details, see the [configuration architecture](https://github.com/knave-de/knave/blob/master/docs/architecture/configuration.md) and [shell configuration boundary](https://github.com/knave-de/knaveshell/blob/master/docs/architecture/configuration.md).

The desktop is experimental and under active development. Check the current source before relying on a setting or installation procedure.
